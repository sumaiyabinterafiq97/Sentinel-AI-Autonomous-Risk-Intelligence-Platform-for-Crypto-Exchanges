# Sentinel AI — Web (M11)

React + TypeScript + Vite SPA (ADR-019). Presentation only.

## M11 scope

- SCR-00–15 / WF-1–8 against existing OpenAPI paths via the DASH BFF
- MFA step after login (simulation 6-digit)
- SSE + poll fallback
- A11y design-target patterns (not WCAG certified)
- No V2 SEC / REPORT / OPS / WALLET routes

## Commands

```bash
cd web
npm install
npm test
npm run lint
npm run build
npm run dev
```
